Project Information

About the Project

A software-based repository and simulation environment for programmable digital logic circuits.

Project Objective

The system provides a structured way to define, save, load, simulate and validate programmable logic circuits. The digital logic model forms the core of the application, while the web interface provides accessible visualization and interaction.
